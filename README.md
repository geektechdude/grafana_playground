# grafana_playground
Set up Grafana and components via individual Docker Compose files. Also included is some Terraform to help configure Grafana.

The aim of this repository is to allow for easy set up of Grafana and related stack for discovery and learning purposes.

```
Directory Setup:


- alloy
  - README.md

- grafana
  - README.md

- loki
  - README.md

- prometheus
  - README.md

- terraform
  - README.md

```
Each directory contains a README.md to explain what the directory is for and explain the files inside. If you are only interested in running Grafana via Docker then head straight for the grafana directory.
